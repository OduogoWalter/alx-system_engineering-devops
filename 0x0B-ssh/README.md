# 0x0B. SSH

## Introduction
This project focuses on the use of SSH (Secure Shell) for secure communication over a network. It is a critical tool for DevOps, network administration, system administration, and security.

## Background Context
As part of this project, you have been provided access to an Ubuntu server located in a datacenter. Unlike the earlier stages of the application process where you used passwords, you will now connect to the server using an RSA key. The server is already configured with the public key you created in a previous project.

You can find your server information, including the IP address and username required to connect via SSH, in the "My Servers" section of the intranet.

**Note:** The server runs on an Ubuntu 20.04 LTS environment.
